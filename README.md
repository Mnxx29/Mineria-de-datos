## 🔧 Requisitos

Para ejecutar los notebooks, necesitas:

```bash
pip install jupyter numpy pandas matplotlib seaborn scikit-learn
```

## 📖 Cómo Usar

1. Clona el repositorio:
```bash
git clone https://github.com/Mnxx29/Mineria-de-datos.git
cd Mineria-de-datos
```

2. Instala las dependencias:
```bash
pip install -r requirements.txt  # si existe
# O instala manualmente: pip install jupyter numpy pandas matplotlib seaborn
```

3. Inicia Jupyter:
```bash
jupyter notebook
```

4. Abre los notebooks `.ipynb` en el navegador y explora los ejercicios
